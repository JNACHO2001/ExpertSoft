# Proyecto Backend REST para gestión de datos

## Descripción

Este proyecto implementa una API REST que permite gestionar datos a través de operaciones básicas de creación, lectura, actualización y eliminación (CRUD). El backend está diseñado para recibir, procesar y responder solicitudes HTTP, facilitando la interacción con una base de datos y soportando múltiples tipos de operaciones.

---

## Tecnologías y librerías utilizadas

- Node.js para el entorno de ejecución del backend.
- Express como framework para la creación de servidores HTTP y definición de rutas.
- MySQL como sistema gestor de base de datos relacional.
- mysql2 para la conexión y ejecución de consultas en MySQL.
- cors para permitir solicitudes HTTP desde diferentes orígenes.
- csv-parser para importar datos desde archivos CSV.

---

## Pasos para configurar y ejecutar el proyecto

### 1. Inicializar el proyecto

- Crear la carpeta del proyecto y acceder a ella.
- Ejecutar el comando para inicializar npm y generar el archivo package.json:
  
  ```bash
  npm init -y
  ```

2. Instalar las dependencias necesarias

    Instalar Express para crear el servidor HTTP:

    ```bash
    npm install express
    ```

    Instalar mysql2 para la conexión y manipulación de la base de datos MySQL:

    ```bash
    npm install mysql2
    ```

    Instalar cors para gestionar solicitudes HTTP entre diferentes dominios:

    ```bash
    npm install cors
    ```

    (Opcional) Instalar csv-parser para importar datos desde archivos CSV:

    ```bash
    npm install csv-parser
    ```

3. Configurar la base de datos

    Acceder a MySQL mediante consola o herramientas gráficas.

    Crear la base de datos que usará la aplicación.

    Definir las tablas y campos requeridos para la gestión de los datos.

4. Configurar la conexión a la base de datos

    Crear un archivo para configurar la conexión usando createConnection de mysql2.

    Establecer los parámetros de conexión: host, usuario, contraseña y nombre de la base de datos.

    Exportar esta conexión para utilizarla en el servidor.

5. Crear el servidor y las rutas

    Crear el archivo principal del servidor con Express.

    Configurar middlewares: cors para permitir orígenes cruzados y express.json() para parsear JSON.

    Definir rutas para cada recurso o entidad con sus correspondientes métodos HTTP (GET, POST, PUT, DELETE).
